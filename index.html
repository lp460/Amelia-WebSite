Pourquoi Amelia

Une dictée qui se comporte comme une fonction native du Mac.

Amelia ne vous oblige pas à travailler dans une application séparée. Elle s’intègre au flux existant : vous placez le curseur, vous parlez, le texte arrive.

⌂

Votre voix reste sur votre Mac

Audio, texte, historique et métriques restent locaux. La transcription repose sur WhisperKit et CoreML, sans API cloud sur le chemin de dictée.

0 octet audio envoyé au cloud
⚡

Fast Path

Smart Bar, modèle local chaud et routeur d’injection sont conçus pour réduire le délai entre la fin de votre phrase et le texte visible.

⌨

Injection intelligente

Accessibility API en priorité, puis presse-papier restauré et CGEvent Unicode en fallback.
